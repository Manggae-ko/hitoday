방 하나 만들고 초대 코드를 단톡에 뿌리면, 다 같이 서로의 바탕화면 아래에 나타나요. 말하면 말풍선이 떠요.

내 화면 다들 뭐해? 일하는 척 ㅋㅋ
민지 화면 다들 뭐해? 일하는 척 ㅋㅋ
맥 다운로드 윈도우 다운로드 Intel 맥이라면
  1. 설치하기맥은 응용 프로그램 폴더로 끌어다 놓고, 윈도우는 더블클릭 한 번이면 끝.
  2. 방 만들고 초대하기"새 방 만들기"를 누르고 초대 코드를 단톡방에 보내요. 최대 12명.
  3. 그냥 켜두기컴퓨터를 켜면 알아서 실행돼요. 앱이 꺼진 친구는 화면에서 졸고 있어요.

자주 묻는 것

처음 열 때 경고가 떠요

맥 "열지 않음" 창이 뜨면 완료를 누르고, 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 그래도 열기 → 비밀번호 입력 → 앱을 다시 열고 열기.

윈도우 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.

한 번만 허용하면 다음부터는 바로 열려요.

회사 컴퓨터에서도 되나요?

회사가 승인되지 않은 앱 실행을 막아뒀다면 쓸 수 없어요. 회사 보안 정책을 먼저 확인해 주세요.

친구가 내 화면을 볼 수 있나요?

아니요. 오가는 건 캐릭터, 이름, 짧은 말뿐이에요. 화면 내용은 절대 보내지 않아요. 초대 코드를 아는 사람만 방에 들어올 수 있으니, 코드는 친구들끼리만 공유해 주세요.
