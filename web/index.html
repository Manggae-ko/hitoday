친구 바탕화면에
놀러 가요

말을 걸면 내 캐릭터가 화면 밖으로 걸어 나가서, 친구 바탕화면으로 들어가요. 거기서 같이 얘기해요.

내 화면 민지네 놀러 감
민지 화면 뭐해? 방금 퇴근함 ㅎㅎ
맥 다운로드 윈도우 다운로드 무료 · 관리자 권한 필요 없음
  1. 설치하고 켜기메뉴바(윈도우는 작업표시줄 오른쪽)에 아이콘이 생겨요.
  2. 코드 교환하기내 코드를 친구한테 보내고, 친구 코드를 등록해요.
  3. 말 걸기캐릭터가 친구 화면으로 걸어가요. 1분 조용하면 집에 돌아와요.

자주 묻는 것

처음 열 때 경고가 떠요

아직 앱 서명 전이라 그래요. 맥: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기". 윈도우: "추가 정보" → "실행".

회사 컴퓨터에서도 되나요?

관리자 권한 없이 설치돼요. 다만 회사가 승인되지 않은 앱 실행을 막아뒀다면 쓸 수 없어요. 회사 보안 정책을 먼저 확인해 주세요.

친구가 내 화면을 볼 수 있나요?

아니요. 오가는 건 캐릭터와 짧은 말뿐이에요. 화면 내용은 절대 보내지 않아요. 서로 코드를 등록한 친구끼리만 놀러 올 수 있어요.

놀러와 · 캐릭터 "말랑이"는 직접 그린 오리지널 캐릭터예요.
