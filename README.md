# 놀러와

친구 바탕화면에 내 캐릭터가 쪽지를 들고 놀러 가는 앱이에요. 맥과 윈도우 둘 다 돼요.

- 내 캐릭터는 화면 오른쪽 아래에 살아요. 클릭하면 설정 창이 열려요.
- "놀러 가기"를 누르면 캐릭터가 화면 오른쪽으로 나가서, 친구 화면 왼쪽으로 쪽지를 들고 들어가요.
- 친구 앱이 꺼져 있으면 쪽지는 서버에 맡겨두고(최대 24시간), 친구가 앱을 켜면 그때 찾아가요.
- 서로의 코드를 등록한 친구끼리만 놀러 갈 수 있어요. 화면 내용은 절대 주고받지 않아요.

## 실행

```bash
git clone <this repo> && cd nolleowa
npm install
npm run server    # 터미널 1: 중계 서버 (ws://localhost:8787)
npm start         # 터미널 2: 앱
```

### 한 대의 맥에서 둘이 노는 것처럼 테스트하기

```bash
npm run server
npm run demo:a    # 다른 터미널
npm run demo:b    # 또 다른 터미널
```

A와 B 창에 서로의 코드를 친구 코드로 넣고 저장한 다음, 쪽지를 써서 놀러 가 보세요.
(`demo:a`/`demo:b` 스크립트는 맥·리눅스용이에요. 윈도우에서는 `set NOLLEOWA_PROFILE=a && npx electron .`처럼 실행하세요.)

### 두 대(맥 ↔ 윈도우)로 연결하기

두 컴퓨터가 같은 서버를 봐야 해요.

- 같은 와이파이: 서버를 띄운 컴퓨터의 IP로 설정 → 서버 주소에 `ws://192.168.x.x:8787`
- 인터넷 너머: `server/relay.js`를 Render·Fly.io·Railway 같은 곳에 올리고 `wss://내-서버-주소`를 입력해요.
  `NOLLEOWA_SERVER=wss://...` 환경변수로 기본 주소를 바꿀 수도 있어요.

릴스용으로 찍을 때는 두 화면을 나란히 두면, 왼쪽 화면에서 나간 캐릭터가 오른쪽 화면으로 들어가는 장면이 나와요.

## 구조

| 경로 | 역할 |
| --- | --- |
| `shared/protocol.js` | 앱·서버가 같이 쓰는 메시지 형식과 검증 |
| `server/relay.js` | 친구 사이 신호 중계, 꺼져 있는 친구용 대기열, 연타 방지 |
| `src/main/` | Electron 메인: 프로필 저장, 서버 연결, 창·트레이 |
| `src/renderer/overlay.*` | 투명한 전체 화면 창, 캐릭터 연출 (캐릭터 위가 아니면 클릭이 바탕화면으로 통과) |
| `src/renderer/control.*` | 내 코드·친구 코드·쪽지 쓰는 설정 창 |
| `scripts/snapshot.js` | 화면을 띄우지 않고 렌더링해서 PNG로 저장 (`npm run snapshot -- <폴더>`) |

## 아직 안 된 것

- 코드를 아는 사람은 내 코드로 접속할 수 있어요. 공개 배포 전에 기기별 비밀 키를 붙여야 해요.
- 친구는 한 명만 등록돼요.
- 서버를 재시작하면 대기 중인 쪽지가 사라져요 (메모리에만 저장).
- 맥 앱 서명·공증은 아직 안 했어요. 압축 파일로 배포하면 처음 열 때 "우클릭 → 열기"가 필요해요.
