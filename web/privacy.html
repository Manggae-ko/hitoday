한눈에 보기

  • 회원가입이 없어요. 이메일, 전화번호, 실명을 받지 않아요.
  • 내 화면 내용은 절대 보내지 않아요. 오가는 건 캐릭터, 닉네임, 짧은 말뿐이에요.
  • 대화 내용은 서버 메모리에만 잠깐 있고, 디스크에 저장하지 않아요.
  • 정보를 팔거나 광고에 쓰지 않아요.

1. 앱이 서버로 보내는 정보

  • 내 코드: 앱이 처음 켜질 때 만드는 무작위 영문·숫자 6자리예요.
  • 기기 키: 다른 사람이 내 코드를 흉내 내지 못하게 하는 값이에요. 서버에는 원래 값이 아니라 되돌릴 수 없게 바꾼 값(해시)만 파일로 저장해요.
  • 닉네임, 고른 캐릭터와 색, 화면 아래 내 캐릭터 위치, 들어가 있는 방 코드: 같은 방 친구 화면에 나를 보여주는 데 써요. 서버 메모리에만 두고 디스크에 저장하지 않아요.
  • 대화 메시지: 같은 방 사람에게 전달해요. 나중에 들어온 친구가 볼 수 있게 방마다 최근 30개까지만 메모리에 두고, 서버가 다시 시작되면 사라져요.
  • 직접 올린 캐릭터 그림: 같은 방 친구에게 보여주려고 메모리에만 둬요. 서버가 다시 시작되면 사라지고, 앱이 다시 보내요.
  • 미니게임 선택(가위바위보 손, 반응속도 클릭 시각): 결과를 정하는 데만 쓰고 저장하지 않아요.

2. 이용 통계와 접속 기록

  • 이용 통계: 날짜별 숫자만 세요(홈페이지 방문 수, 다운로드 수, 새 기기 수, 접속 수, 만든 방 수, 메시지 수, 게임 횟수, 최대 동시 접속 수). 닉네임, 코드, 메시지 내용, IP 주소는 통계에 남기지 않아요.
  • 접속 기록: 서버를 안전하게 운영하려고 웹 서버가 접속 시각, IP 주소, 요청한 주소를 기록해요. 정해진 용량(약 30MB)이 차면 오래된 기록부터 자동으로 지워져요.
  • 운영자 알림: 새 사용자가 처음 접속하거나 방이 만들어지거나 친구가 방에 들어오면, 운영자 전용 채팅 채널(Discord)로 닉네임이 담긴 짧은 알림이 가요. 방 코드와 대화 내용은 보내지 않아요.
  • 홈페이지 방문 통계: 홈페이지(jakdang.naegoworks.com)에서만 Google Analytics를 써요. 앱 안에서는 쓰지 않아요.

3. 정보를 맡기는 곳

다른 회사에 정보를 팔거나 넘기지 않아요. 서비스를 돌리려고 아래 서비스를 써요.

  • 네이버 클라우드(한국): 작당모의 서버
  • GitHub: 설치 파일과 업데이트 파일 내려받기
  • Google Analytics: 홈페이지 방문 통계
  • Discord: 운영자 알림(닉네임)
  • Microsoft Store: 스토어에서 설치한 경우 설치와 업데이트

4. 지우고 싶을 때

  • 앱을 지우면 내 컴퓨터에 있던 코드, 닉네임, 캐릭터 그림이 함께 지워져요.
  • 방에서 나가면 그 방 친구 화면에서 내 캐릭터가 사라져요.
  • 서버에 남은 기기 키 해시를 지우고 싶으면 앱 설정 창에 보이는 내 코드와 함께 아래 메일로 알려 주세요. 확인 후 지워 드려요.
