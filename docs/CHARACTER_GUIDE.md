# 캐릭터 가이드

내장 캐릭터는 `ghost`, `rabbit`, `penguin` 세 종이며 방 색 12개마다 64×64 RGBA 스프라이트 시트를 가집니다. 시트는 16×16 셀 4×4이고 화면에서는 최근접 보간으로 3배인 48px로 표시합니다. 업로드 이미지는 단일 16×16 PNG 또는 같은 64×64 시트를 허용합니다.

행별 프레임은 idle 2개, walk 4개, talk 2개, sleep 2개입니다. 남은 셀은 완전히 투명합니다. 모든 사용 프레임은 바닥 y=15에 닿고, 폭은 11px 이하입니다. ghost와 penguin은 높이 13px 이하, rabbit은 4px 귀를 포함해 15px 이하이며 몸통 폭은 8px 이하입니다.

방 색은 `ROOM_PALETTE`의 손으로 고른 12색을 사용합니다. 외곽선은 `#3a2f2a`이고 ghost와 rabbit은 밝은 방 색 틴트, penguin은 어두운 방 색 등과 흰 배를 씁니다. 뜬 눈은 1×2 세로, 감은 눈은 2×1 가로이며 sleep 프레임에는 별도의 수면 문자를 그리지 않습니다.

`node scripts/make-sprites.js`로 스프라이트와 미리보기를, `npm run icons`로 앱·트레이 아이콘을 결정적으로 다시 생성합니다.
